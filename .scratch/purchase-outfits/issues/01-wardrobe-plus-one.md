# 01: 가진 옷 + 새 옷 1벌 구매 추천

**What to build:** 추천 모듈에 구매 추천 코디를 더한다. LLM이 그날의 조건(격식 수준·날씨·선호)으로 새 옷 후보 6벌을 제안하면, 가진 옷과 비슷한 후보는 버리고 정리한 옷이 있으면 되돌리기로 바꾼 뒤, 각 후보를 넣은 최고점 코디를 만들어 점수 순·새 옷 중복 없이 최대 3개를 돌려준다. 새 옷마다 새로 어울리는 가진 옷 수를 담는다. 같은 날·격식·옷장이면 저장한 후보를 다시 쓰고, LLM이 실패하면 unavailable. 메인에 "구매 추천으로 보기"와 구매 추천 화면을 둔다. (스펙 스토리 1~8, 10~12)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 코디마다 새 옷 1벌과 가진 옷으로 이루어지고, 새 옷이 겹치지 않으며 최대 3개다
- [ ] 가진 옷과 비슷한 후보는 빠진다
- [ ] 그날의 격식 수준을 지킨다
- [ ] LLM이 실패하면 unavailable이다
- [ ] 같은 날 다시 부르면 LLM을 다시 부르지 않는다
