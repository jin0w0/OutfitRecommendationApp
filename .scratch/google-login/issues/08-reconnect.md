# 08: 연동 만료와 재연동

**What to build:** 토큰 갱신이 실패하거나 구글에서 권한이 철회되면 캘린더 연동이 "재연동 필요" 상태가 되고 안내가 뜬다. 버튼 하나로 다시 연동하며, 같은 계정으로 재연동하면 이전 캘린더 선택이 유지된다. (스펙 스토리 40~43)

**Blocked by:** 06

**Status:** ready-for-agent

- [x] 갱신 실패 시 캘린더 접근 토큰 얻기가 "재연동 필요"를 돌려주고 상태가 기록된다
- [x] 같은 계정 재연동 시 캘린더 선택이 유지되고 상태가 정상으로 돌아온다
- [x] 다른 계정으로 재연동하면 연동 변경 규칙을 따른다(09 이후)
