# 02: 구글 로그인과 소개 화면

**What to build:** 방문자는 소개 화면만 볼 수 있고, 구글로 로그인하면 사용자가 자동으로 만들어져 이름과 프로필 사진이 보인다. 로그인하지 않은 채 보호된 화면에 들어가면 로그인으로 안내되고, 로그인 후 원래 화면으로 돌아온다. 로그인은 직접 로그아웃할 때까지 유지되고, 현재 기기에서 로그아웃할 수 있다. 계정 모듈 골격, 가짜 구글 어댑터, "구글 계정 ○○으로 로그인 끝난 상태"를 만드는 테스트 도우미, `proxy` 기반 접근 제어를 여기서 만든다. (스펙 스토리 1~15, 17 제외)

- [x] 로그아웃하면 그 기기의 세션만 사라진다
