# 09: 연동 해제와 변경

**What to build:** 사용자가 해제 전에 지워지는 것과 남는 것을 확인받고 캘린더 연동을 해제한다. 구글 권한을 철회하고 연결과 캘린더 선택을 지운다. 철회가 실패해도 해제는 완료된다. 다른 계정으로 바꿀 때도 같은 규칙이다. 다른 사용자의 연동에는 영향이 없다. 아직 없는 기능의 데이터(일정 판단 수정값)를 지울 수 있도록, 해제 시 정리할 데이터를 등록하는 자리를 계정 모듈에 둔다. (스펙 스토리 44~50)

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 해제하면 연동 계정의 토큰 철회가 호출된다
- [ ] 철회가 실패해도 해제가 완료된다
- [ ] 같은 구글 계정을 연동한 다른 사용자의 연동은 그대로다
- [ ] 로그인 계정과 같은 계정을 해제하면 로그인은 유지된다
- [ ] 등록된 정리 작업이 해제 시 호출된다
