# 04: 기본 지역 온보딩

**What to build:** 처음 로그인한 사용자는 기본 지역을 정한다. 정하지 않으면 온보딩이 끝나지 않은 것으로 보고 다음에 다시 안내한다. 설정에서 기본 지역을 바꿀 수 있다. (스펙 스토리 19·20·24~27)

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 현재 사용자 조회가 기본 지역과 온보딩 상태를 돌려준다
- [x] 기본 지역이 없는 사용자가 보호된 화면에 들어가면 온보딩으로 간다
- [x] 기본 지역은 정해진 지역 목록 안에서만 고를 수 있다
