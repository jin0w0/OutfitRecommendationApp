# 10: 탈퇴

**What to build:** 사용자가 지워지는 데이터를 확인받고 탈퇴한다. 로그인 계정과 캘린더 연동 계정 모두의 권한 철회를 시도한 뒤 사용자와 모든 데이터를 지우고 모든 기기에서 로그아웃한다. 철회가 실패해도 탈퇴는 진행된다. 같은 구글 계정으로 다시 로그인하면 빈 새 사용자다. 옷장 등 아직 없는 기능의 데이터를 위해 탈퇴 시 정리할 데이터를 등록하는 자리를 둔다. (스펙 스토리 51~57)

**Blocked by:** 09

**Status:** ready-for-agent

- [ ] 탈퇴 시 두 계정 모두 철회가 시도된다
- [ ] 탈퇴 뒤 그 사용자의 세션, 계정 연결, 캘린더 연동, 기본 지역이 남지 않는다
- [ ] 같은 이메일로 다시 로그인하면 새 사용자다
- [ ] 등록된 정리 작업이 탈퇴 시 호출된다
