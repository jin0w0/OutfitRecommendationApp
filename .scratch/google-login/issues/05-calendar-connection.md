# 05: 캘린더 연동 (다른 구글 계정 포함)

**What to build:** 사용자가 설정에서 캘린더 연동을 시작하면 구글 계정을 다시 골라 calendar.readonly 권한을 준다. 로그인 계정과 다른 계정, 같은 계정 모두 가능하다. 토큰은 암호화해서 저장하고, 설정에 연동된 계정이 보인다. 계정 모듈의 "캘린더 접근 토큰 얻기"가 연동 계정의 토큰을 돌려준다(필요하면 갱신). 시작할 때 Better Auth가 같은 제공자의 다른 이메일 계정을 별도 연결로 저장하는지 작게 검증한다. (스펙 스토리 28~31·35~39)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 로그인 계정 A, 연동 계정 B일 때 캘린더 접근 토큰은 B의 것이다
- [ ] 로그인 계정과 같은 계정을 연동하면 기존 연결에 권한이 더해진다
- [ ] DB에 저장된 토큰은 평문이 아니다
- [ ] 같은 구글 계정을 여러 사용자가 연동해도 서로 영향이 없다
- [ ] 연동하지 않은 사용자의 캘린더 접근 토큰 요청은 "연동 없음"을 돌려준다
