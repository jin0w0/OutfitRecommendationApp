# 05: 캘린더 연동 (다른 구글 계정 포함)

**What to build:** 사용자가 설정에서 캘린더 연동을 시작하면 구글 계정을 다시 골라 calendar.readonly 권한을 준다. 로그인 계정과 다른 계정, 같은 계정 모두 가능하다. 연동은 Better Auth 계정 연결이 아니라 계정 모듈의 자체 OAuth 흐름으로 처리하고 캘린더 연동 테이블에 저장한다(ADR-0002). 토큰은 암호화해서 저장하고, 설정에 연동된 계정이 보인다. 계정 모듈의 "캘린더 접근 토큰 얻기"가 연동 계정의 토큰을 돌려준다(만료되었으면 갱신). (스펙 스토리 28~31·35~39)

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 로그인 계정 A, 연동 계정 B일 때 캘린더 접근 토큰은 B의 것이다
- [x] 캘린더 연동한 계정 B로 로그인하면 A가 아닌 다른 사용자가 된다
- [x] 로그인 계정과 같은 계정도 연동할 수 있다
- [x] 같은 구글 계정을 여러 사용자가 연동해도 서로 영향이 없다
- [x] 다른 사용자가 시작한 연동 요청(state)으로는 연동을 마칠 수 없다
- [x] 구글 동의를 취소하면 연동이 생기지 않는다
- [x] 만료된 접근 토큰은 요청 시 갱신된다
- [x] DB에 저장된 토큰은 평문이 아니다
- [x] 연동하지 않은 사용자의 캘린더 접근 토큰 요청은 "연동 없음"을 돌려준다
