# 03: 캘린더 일정 불러와 표시

**What to build:** 캘린더를 연동한 사용자가 날짜를 고르면, 그날 등록된 일정 목록(제목, 시작·종료 시간, 종일 여부, 장소)이 추천 화면에 보인다. 캘린더 어댑터는 계정 모듈에서 캘린더 접근 토큰을 받아, 사용자가 고른 캘린더에서만 그날의 일정을 읽는다(읽기 전용). 종일 일정도 포함한다. 일정에 장소가 있으면 그 장소의 날씨를 쓰고, 장소를 예보 지점으로 바꿀 수 없거나 장소가 없으면 기본 지역의 날씨를 쓴다. 장소 문자열을 지역으로 바꾸는 방법은 구현할 때 정한다. 연동이 만료되었거나 철회되었으면 이미 있는 재연동 안내를 보여 주고, 결과의 누락 정보에 캘린더 실패를 넣은 채 일정 없이 추천한다. 연동하지 않은 사용자는 지금처럼 상황을 직접 고른다. 이 티켓에서는 일정의 종류·격식 판단을 하지 않는다. 일정이 있으면 일단 기준 일정을 표시만 하고 격식은 기본값으로 둔다. (스펙 스토리 3, 4, 6, 15, 16, 17, 47, 48)

- [x] 종일 일정도 결과에 들어 있다
- [x] 일정의 장소가 다른 지역이면 그 지역의 날씨가 쓰인다
- [x] 장소가 없는 일정은 기본 지역의 날씨가 쓰인다
- [x] 연동이 만료되었으면 누락 정보에 캘린더 실패가 들어 있고, 추천은 일정 없이 나온다
- [x] 연동하지 않은 사용자는 캘린더 어댑터를 거치지 않고 직접 고른 상황으로 추천받는다
- [ ] 화면에 일정의 제목·시간·장소가 보이고, 만료되었으면 재연동 안내가 보인다
