# 05: 일정 판단 직접 고치기

**What to build:** 앱이 잘못 판단한 일정의 종류나 격식 수준을 사용자가 화면에서 고치면, 고친 값으로 다시 추천받는다. 수정값은 사용자와 캘린더 일정 식별자 기준으로 Neon에 저장한다. 같은 일정을 다시 볼 때는 LLM 판단보다 수정값이 우선한다. 탈퇴하면 수정값도 지워진다. (스펙 스토리 12)

**Blocked by:** 04

**Status:** ready-for-agent

- [x] 격식을 포멀에서 캐주얼로 고치면 다시 받은 추천은 캐주얼 기준으로 골라진다
- [x] 고친 일정을 다음에 다시 불러와도 고친 값이 쓰이고, LLM에는 다시 묻지 않는다
- [x] 다른 사용자의 같은 일정 식별자에는 수정값이 적용되지 않는다
- [x] 탈퇴하면 그 사용자의 수정값이 남지 않는다
- [x] 화면에서 종류와 격식 수준을 고르고 다시 추천받을 수 있다
