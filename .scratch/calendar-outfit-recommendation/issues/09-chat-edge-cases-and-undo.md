# 09: 대화 수정의 예외와 되돌리기

**What to build:** 대화 수정에서 예외 상황을 안내하고, 수정 전 추천으로 되돌릴 수 있다. 수정 조건이 기준 일정의 격식 수준과 충돌하면(예: 결혼식에 트레이닝복) 경고를 함께 돌려주되 수정은 진행한다. 옷장으로 조건을 만족하는 코디를 만들 수 없으면 "구성 불가"를 돌려주고, 만족하지 못한 조건을 알려 준다. 이때 이전 코디는 그대로 유지된다. 코디와 관계없는 메시지는 "무관한 메시지" 조건으로 해석해서 코디를 바꾸지 않고 코디 수정 대화로 다시 안내한다. 사용자는 추천 세션의 이력에서 이전 단계(처음 추천 포함)로 되돌아갈 수 있다. (스펙 스토리 39~42)

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 결혼식이 기준 일정일 때 "캐주얼하게"를 요청하면 격식 충돌 경고와 함께 수정된 코디가 나온다
- [ ] 옷장에 남은 바지가 없는데 "이 바지 말고"를 하면 "구성 불가"와 만족 못 한 조건이 나오고, 코디는 바뀌지 않는다
- [ ] "오늘 점심 뭐 먹지?" 같은 메시지에는 코디가 바뀌지 않고 다시 안내하는 응답이 나온다
- [ ] 무관한 메시지는 누적 수정 조건에 더해지지 않는다
- [ ] 되돌리기를 하면 처음 추천의 코디와 수정 조건 상태로 돌아간다
- [ ] 화면에 경고·구성 불가·다시 안내 메시지와 되돌리기 버튼이 보인다
