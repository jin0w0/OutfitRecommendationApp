# 08: 대화로 코디 수정 (기본)

**What to build:** 사용자가 추천을 받은 뒤 "좀 더 캐주얼하게", "이 바지 말고 다른 걸로", "이 셔츠는 꼭 입고 싶어", "좀 더 밝은 색으로"처럼 말하면 코디가 수정된다. 코디 추천 모듈의 두 번째 진입점 *대화로 수정하기*가 이전 추천과 메시지를 받는다. LLM 어댑터가 메시지를 구조화된 **수정 조건**(스타일 방향, 색상 방향, 아이템 제외, 아이템 고정)으로 바꾼다. 수정 조건은 대화 동안 누적되고, 새 조건이 이전 조건과 충돌하면 새 조건이 이긴다. LLM은 코디를 직접 고르지 않는다. 수정된 코디도 같은 점수 계산과 추천 이유 생성을 거친다. 결과에는 누적된 수정 조건과, 이전 코디와 비교해 무엇이 왜 바뀌었는지가 들어 있다. 추천 세션(사용자, 날짜, 수정 단계별 추천 결과 이력, 누적 수정 조건)은 Neon에 저장하고 탈퇴하면 지워진다. (스펙 스토리 32~38)

**Blocked by:** 06

**Status:** ready-for-agent

- [x] "이 바지 말고" 이후의 코디에는 그 바지가 없다
- [x] "이 셔츠는 꼭 입고 싶어" 이후의 코디에는 그 셔츠가 있다
- [x] "캐주얼하게" 이후의 코디는 이전보다 격식이 낮은 옷으로 구성된다
- [x] "캐주얼하게" 다음에 "바지만 바꿔줘"를 해도 캐주얼 조건이 유지된다
- [x] "캐주얼하게" 다음에 "포멀하게"를 하면 포멀 조건이 이긴다
- [x] 수정 결과에 바뀐 슬롯과 그 이유가 들어 있다
- [x] 수정 결과에도 처음 추천과 같은 형식의 추천 이유가 붙는다
- [x] 수정된 코디를 "입을게요"로 수락할 수 있다
- [x] 화면에서 추천 아래 대화 입력으로 수정 요청을 보낼 수 있다
