# 04: LLM 일정 분석

**What to build:** 앱이 일정의 제목·메모·장소를 보고 **일정의 종류**(출근, 면접, 결혼식, 데이트, 운동 등)와 **격식 수준**(캐주얼 / 세미 포멀 / 포멀)을 판단하고, 그 결과를 화면에 보여 준다. 이 티켓이 LLM 어댑터를 도입한다. 실제 구현은 OpenAI API의 구조화 출력을 쓴다. 입력과 출력은 구조화되어 있고, 테스트의 가짜 LLM은 정해진 입력에 정해진 출력을 돌려준다. LLM에는 판단에 필요한 제목, 메모, 장소만 보내고 참석자 정보는 보내지 않는다. 하루에 일정이 여러 개면 격식 수준이 가장 높은 일정을 기준 일정으로 삼고, 나머지 일정과 격식 차이가 큰 옷은 감점한다. LLM이 실패하면 기본 격식으로 추천을 계속하고 누락 정보에 LLM 실패를 넣는다. API 키 발급은 사람이 해야 한다. (스펙 스토리 9~11, 13~15, 47~49)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] "결혼식" 일정은 종류가 결혼식, 격식이 포멀로 판단되고 포멀한 옷이 골라진다
- [ ] 출근(세미 포멀)과 결혼식(포멀)이 같은 날이면 결혼식이 기준 일정이 된다
- [ ] 기준 일정 외 일정과 격식 차이가 큰 옷은 같은 조건의 다른 옷보다 덜 골라진다
- [ ] LLM에 보내는 입력에 참석자 정보가 없다
- [ ] LLM이 실패해도 추천이 나오고, 누락 정보에 LLM 실패가 들어 있다
- [ ] 화면에 각 일정의 판단된 종류와 격식 수준이 보인다
