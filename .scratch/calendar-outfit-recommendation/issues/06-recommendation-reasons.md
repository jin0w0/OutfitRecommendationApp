# 06: 추천 이유

**What to build:** 추천된 코디와 함께 **추천 이유**가 보인다. 추천 이유는 점수 계산에서 기여도가 컸던 상위 2~3개 요소 각각에 대해, *구조화된 근거*(요소, 관련 옷, 사실값)와 *문장*으로 이루어진다. 예를 들면 색상 조합(어떤 색끼리 왜 어울리는지), 날씨 적합성(기온·강수에 맞는 소재와 두께), 일정과의 연관성(종류와 격식 수준에 맞는지)이다. 근거는 점수 계산 과정에서만 나온다. LLM은 근거를 자연스러운 문장으로 다듬기만 하고, 근거에 없는 사실을 더하지 않는다. LLM이 실패하면 근거로 템플릿 문장을 만들고 누락 정보에 LLM 실패를 넣는다. 테스트는 문장이 아니라 구조화된 근거를 검증한다. (스펙 스토리 26~31, 49)

**Blocked by:** 02, 04

**Status:** ready-for-agent

- [ ] 추천 이유는 2~3개이고, 각각 요소와 관련 옷과 사실값을 담는다
- [ ] 추천 이유의 요소는 요소별 점수에서 기여도가 가장 큰 것들이다
- [ ] 5도인 날 아우터가 골라졌으면 날씨 적합성 근거에 그 아우터와 기온이 들어 있다
- [ ] 결혼식 일정이면 일정 연관성 근거에 일정의 종류와 격식 수준이 들어 있다
- [ ] LLM이 실패해도 각 근거에 템플릿 문장이 붙는다
- [ ] 화면에서 코디 아래에 추천 이유가 짧게 보인다
