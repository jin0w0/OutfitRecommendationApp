# 02: 날씨 반영

**What to build:** 추천에 그 날짜의 날씨(기온, 강수 여부)가 반영된다. 이 티켓에서는 사용자의 **기본 지역**을 기준으로 한다. 날씨 어댑터는 날짜와 좌표를 받아 기온·강수 여부를 돌려주거나 "예보 없음"을 돌려준다. 실제 구현은 기상청 API(공공데이터포털)를 쓴다. 가까운 날짜는 단기예보로, 그 뒤 날짜는 중기예보로 조회하고, 중기예보 범위 밖이면 "예보 없음"이다. 기본 지역의 위경도는 기상청 격자 좌표로 바꾸고, 중기예보 지역 코드와도 연결한다. 날씨 점수(기온에 맞는 두께, 비 오는 날 소재)가 요소별 점수에 들어가고, 추운 날에는 아우터 슬롯이 채워진다. 날씨를 못 쓰면 결과의 누락 정보에 "날씨 미반영"을 넣고 나머지 정보로 추천을 계속한다. API 키 발급은 사람이 해야 한다. 키가 없어도 가짜 어댑터로 끝까지 테스트할 수 있다. (스펙 스토리 16~19, 21, 47, 48)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 기온이 5도인 날에는 코디에 아우터가 들어간다
- [ ] 기온이 25도인 날에는 아우터가 없고 얇은 옷이 골라진다
- [ ] 비 오는 날에는 비에 약한 소재의 신발이 감점된다
- [ ] 결과에 사용한 날씨(기온, 강수 여부)가 들어 있다
- [ ] 예보 범위 밖의 날짜는 "날씨 미반영" 누락 정보와 함께 추천된다
- [ ] 날씨 어댑터가 실패해도 추천이 나오고, 누락 정보에 날씨 실패가 들어 있다
- [ ] 화면에 사용한 날씨, 또는 날씨가 반영되지 않았다는 안내가 보인다
