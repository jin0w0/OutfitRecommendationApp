# 01: 일정 없이 옷장만으로 첫 코디 추천

**What to build:** 로그인한 사용자가 홈 화면에서 날짜를 고르고, 상황(출근, 등교, 약속 등)을 직접 고르거나 "일정 없음"을 두면, 자기 옷장의 옷으로만 구성된 코디를 추천받는다. 이 티켓이 코디 추천 모듈의 뼈대를 만든다: 외부에 드러나는 진입점은 *날짜로 추천받기* 하나이고, 옷장 저장소·캘린더·날씨·LLM은 좁은 어댑터 인터페이스로 주입한다. 테스트는 이 진입점만 부르고, 어댑터는 메모리 기반 가짜로 바꾼다(계정 모듈의 테스트 하네스와 같은 방식). 이 티켓에서는 캘린더·날씨·LLM 어댑터가 "없음"을 돌려준다고 보고 진행한다.

옷장 저장소는 Neon에 둔다. 옷마다 종류(슬롯), 색상, 계절, 스타일, 격식 수준, 두께를 갖고, 사용자 선호(색상·스타일)도 저장한다. 옷 등록은 범위 밖이므로 시연용 시드 데이터를 넣는다. 코디는 요소별 점수(일정과의 격식 일치, 색상 조합, 스타일 일관성, 선호도)의 가중합이 가장 높은 조합으로 고른다. 가중치는 모든 사용자에게 같은 기본값을 쓴다. 라우트와 화면은 모듈을 부르는 얇은 층으로 둔다. (스펙 스토리 7, 8, 20, 21, 23, 24)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 추천된 코디에는 상의·하의·신발, 또는 원피스·신발이 들어 있다
- [x] 추천된 옷은 모두 그 사용자의 옷장에 있는 옷이다 (다른 사용자의 옷은 나오지 않는다)
- [x] 직접 고른 상황이 포멀이면(예: 면접) 격식 수준이 포멀인 옷이 골라진다
- [x] "일정 없음"이면 일정 점수 없이 선호와 색상만으로 추천된다
- [x] 선호 색상의 옷이 같은 조건의 다른 옷보다 먼저 골라진다
- [x] 슬롯 하나라도 채울 옷이 없으면 "구성 불가"와 빠진 슬롯을 돌려준다
- [x] 결과에 요소별 점수가 들어 있다
- [ ] 홈 화면에서 날짜와 상황을 고르면 추천 코디가 보인다
