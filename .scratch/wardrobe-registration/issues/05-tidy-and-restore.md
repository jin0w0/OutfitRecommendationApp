# 05: 정리하기와 되돌리기

**What to build:** 사용자가 옷을 정리하면(안내 확인 후) 옷장과 추천, 대화형 수정에서 빠지고, 정리한 옷 목록에 나온다. 지난 착용 기록과 이미 받은 추천 세션에는 정리한 옷이 그대로 보인다. 정리한 옷을 다시 옷장으로 되돌릴 수 있다. (스펙 스토리 38~42, 52)

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 정리한 옷은 옷장 보기에서 빠지고 정리한 옷 보기에 나온다
- [ ] 정리한 옷은 새 추천과 대화형 수정의 코디에 나오지 않는다
- [ ] 지난 착용 기록에는 정리한 옷이 그대로 보인다
- [ ] 되돌리면 다시 추천에 쓰인다
