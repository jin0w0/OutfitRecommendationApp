# 07: 선호 색상·스타일

**What to build:** 사용자가 설정에서 좋아하는 색상(15색)과 스타일을 여러 개 고른다. 처음 가입하면 기본 지역 다음에 선호 단계가 나오고(건너뛰기 가능), 한 번 보거나 건너뛰면 다시 뜨지 않는다. 그다음 캘린더 연동 권유가 이어진다. 바꾼 선호는 다음 추천부터 반영된다. (스펙 스토리 43~48)

**Blocked by:** 01

**Status:** resolved

- [x] 선호를 저장하면 다음 추천의 선호도 점수에 반영된다
- [x] 선호 단계는 기본 지역 뒤에만 뜨고, 넘기면 다시 뜨지 않는다
- [x] 온보딩 순서가 기본 지역 → 선호 → 캘린더 연동 권유다

## Comments

- 이 기능 전에 온보딩을 마친 사용자(캘린더 연동 권유까지 지난 사용자)에게는 선호 단계를 띄우지 않는다. 설정에서 고를 수 있다.
