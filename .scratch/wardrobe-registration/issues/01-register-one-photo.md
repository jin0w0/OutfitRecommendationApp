# 01: 사진 한 장으로 옷 등록

**What to build:** 사용자가 옷 사진 한 장을 고르면 AI가 이름·종류·색상(15색)·계절·스타일·격식 수준·두께·소재를 채운 등록 초안이 나오고, 사용자가 확인·수정하고 추정 착용 빈도를 골라 저장하면 옷장에 들어간다. 옷장 목록에서 그 옷이 사진과 함께 보인다. 이 티켓이 옷장 모듈(사진 분석하기, 등록하기, 옷장 보기, 사진 주소 얻기)과 그 테스트 하네스, 사진 저장소 어댑터(Neon Object Storage, S3 SDK)와 사진 분석 AI 어댑터(OpenAI 이미지 입력), 사진 보기 라우트를 만든다. AI가 실패하면 빈 초안으로 직접 채운다. 사진은 브라우저에서 줄여서 올린다. (스펙 스토리 3, 4, 10~22, 24, 25, 27~30)

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 사진을 분석하면 AI 값으로 채워진 초안이 나오고, 확신하지 못한 항목은 비어 있다
- [x] AI가 실패하면 사진은 남고 빈 초안과 실패 표시가 나온다
- [x] 사진에 옷이 없다고 판단되면 초안에 그 표시가 있다
- [x] 남의 사진 식별자로는 등록할 수 없다
- [x] 목록 밖의 색상·종류 등은 저장할 수 없다
- [x] 등록한 옷은 다음 추천부터 쓰인다
- [x] 사진 주소는 본인 옷에만 나오고 5분짜리 임시 주소다
- [x] 실제 버킷에 넣기·임시 주소로 읽기·지우기를 확인하는 스크립트가 있고 통과한다
