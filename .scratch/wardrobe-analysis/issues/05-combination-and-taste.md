# 05: 조합 부족과 취향 불일치

**What to build:** 이 옷을 넣은 코디 중 색상 조합·스타일 일관성 점수가 모두 0.7 이상인 코디가 2개 미만이면 조합 부족이다(추천 모듈과 같은 점수 함수). 옷의 색상과 스타일이 선호에도, 최근 90일 착용 기록의 상위 3개 색상·스타일에도 없으면 취향 불일치다. 우선순위는 계절 → 상황 → 대체재 → 조합 → 취향. (스펙 스토리 13, 14, 16, 25, 26)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 선호와 자주 입는 색·스타일에서 먼 옷은 취향 불일치다
- [ ] 두 원인이 모두 걸리면 조합 부족이 나온다
