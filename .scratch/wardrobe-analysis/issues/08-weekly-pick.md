# 08: 이번 주에 꺼내 볼 옷

**What to build:** 메인 화면에 이번 주(월~일, 한국 시간)에 꺼내 볼 옷 카드 하나를 보여 준다. 후보는 계절 불일치가 아닌 안 입는 옷이고, 철이 돌아온 옷 먼저, 그다음 오래 안 입은 순서다. 한 주 동안 같은 옷을 보여 주고, "다른 옷 보기"로 이번 주에 보여 주지 않은 다음 후보로 바꾼다(다 보면 처음으로). 저장된 옷이 후보가 아니게 되면 다음 후보로 바뀐다. 후보가 없으면 카드가 없다. 카드에서 분석 화면의 그 옷으로 간다. (스펙 스토리 38~44)

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 같은 주에는 같은 옷, 다음 주에는 다시 고른다
- [ ] 다른 옷 보기는 이번 주에 보여 주지 않은 옷을 고르고, 다 보면 처음으로 돌아간다
- [ ] 이번 주의 옷을 입으면 다른 옷으로 바뀐다
- [ ] 철이 돌아온 옷이 먼저 고른다
- [ ] 후보가 없으면 없음이다
