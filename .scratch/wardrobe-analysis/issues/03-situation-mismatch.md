# 03: 상황 불일치

**What to build:** 최근 60일 추천 세션의 기준 일정 격식 수준이 하나 이상 있고, 그중 어느 것도 옷의 격식 수준과 같지 않으면 상황 불일치로 판정한다. 근거에 옷의 격식과 최근 일정의 격식들을 담는다. 계절 불일치가 먼저다. 추천 세션 저장소에 날짜 범위의 기준 읽기를 추가한다. (스펙 스토리 11, 23)

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 캐주얼 일정만 있었으면 포멀 옷은 상황 불일치다
- [ ] 최근 60일에 기준 일정이 없으면 상황 불일치를 판정하지 않는다
- [ ] 계절 불일치이기도 한 옷은 계절 불일치로 판정된다
