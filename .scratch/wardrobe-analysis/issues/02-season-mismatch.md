# 02: 계절 불일치와 철이 돌아온 옷

**What to build:** 옷의 계절에 지금 계절(한국 시간 달 기준)이 없으면 계절 불일치로 판정하고, 다음에 맞는 계절이 시작되는 달을 근거로 "○월쯤부터 입기 좋아요"를 보여 준다. 정리 제안은 없다. 지금 계절은 맞고 바로 전 계절은 맞지 않았던 옷은 "철이 돌아온 옷"으로 표시한다. (스펙 스토리 10, 21, 22)
