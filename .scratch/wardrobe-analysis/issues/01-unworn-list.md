# 01: 안 입는 옷 목록과 분석 화면

**What to build:** 사용자가 옷장 분석 화면에서 안 입는 옷을 오래 안 입은 순서로 본다. 옷마다 마지막 착용일(또는 입은 적 없음)과 판정이 보인다. 이 티켓에서 판정은 신규 등록(등록 14일 미만)과 물어봐야 함 두 가지뿐이다. 옷장 분석 모듈(분석하기)과 그 하네스, 분석 화면, 옷장 화면의 링크를 만든다. "오늘"은 주입한다. (스펙 스토리 1~8)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 마지막 착용이 30일 이상 전이거나 입은 적 없는 옷이 나오고, 29일 전에 입은 옷은 나오지 않는다
- [ ] 착용 기록이 없으면 추정 착용 빈도로 판단한다(거의 매주·한 달에 몇 번은 제외, 거의 안 입음·빈 값은 포함, 새로 산 옷은 14일 뒤부터)
- [ ] 등록 14일 미만인 옷은 신규 등록으로 판정된다
- [ ] 정리한 옷은 나오지 않는다
- [ ] 오래 안 입은 순서다
