# 01: 조합 부족인 옷을 살리는 한 벌

**What to build:** 한 벌 제안 모듈과 LLM 어댑터의 "한 벌 후보 제안하기"(후보 6개, 값 목록 검사), 제안 저장소(옷장 지문과 함께 후보 저장)를 만든다. 옷장 분석의 조합 부족인 옷 상세 화면에 제안을 최대 3개 보여 준다: 그 옷과 후보가 함께 들어간 잘 어울리는 코디가 2개 이상 새로 생기는 후보만, 새로 생기는 코디 수 순으로, 종류·색상 중복 없이. 옷장에 같은(종류·색상·격식) 옷이 있으면 빼고, 정리한 옷 중에 있으면 되돌리기로 바꾼다. 옷장이 그대로면 LLM을 다시 부르지 않고, LLM이 실패하면 아무것도 보여 주지 않는다. (스펙 스토리 1~5, 7~9, 12~14)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 기준(새 코디 2개 이상)을 넘는 후보만 나오고 코디 수 순서다
- [ ] 최대 3개, 종류·색상 중복 없음
- [ ] 같은 옷이 옷장에 있으면 빠지고, 정리한 옷에 있으면 되돌리기로 나온다
- [ ] 목록 밖 값의 후보는 버린다
- [ ] 옷장이 그대로면 LLM을 다시 부르지 않고, 바뀌면 다시 부른다
- [ ] LLM이 실패하면 빈 목록이다
