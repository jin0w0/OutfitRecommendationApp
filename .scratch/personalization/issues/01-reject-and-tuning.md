# 01: 거절 이유와 추천 맞춤 보기·되돌리기

**What to build:** "다시 추천받기"에 거절 이유 선택(선택 사항)을 붙이고, 추천 모듈에 거절하기를 더한다. 거절 이유의 요소(색 조합→색상, 스타일 취향→선호도, 날씨→날씨, 일정→일정)는 거절마다 1.10배가 되고(기본의 0.5~2배), 날짜로 추천받기·대화로 수정하기·활용 코디와 추천 이유가 사용자 가중치로 점수를 매긴다. 설정의 "내 추천 맞춤"에서 더 신경 쓰는 요소를 보고 처음 상태로 되돌린다. 가중치는 기록에서 매번 계산한다. (스펙 스토리 1~3, 5~9, 13, 14, 22, 24)

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 색 조합으로 거절하면 색상 배수가 1.1이 되고, 다음 추천이 색이 더 잘 어울리는 코디로 바뀐다
- [ ] 이유 없음과 "그냥"은 배수를 바꾸지 않는다
- [ ] 배수는 2를 넘지 않는다
- [ ] 되돌리면 모든 배수가 1이 된다
- [ ] 거절한 뒤 기존처럼 아직 보지 않은 코디가 나온다
