# 캘린더 연동은 Better Auth 계정 연결이 아닌 자체 OAuth 흐름으로

ADR-0001은 캘린더 연동을 Better Auth의 계정 연결(`linkSocial`)로 처리할 계획이었다. 그런데 Better Auth에서 연결된 구글 계정은 **로그인 수단**이 된다. 그래서 캘린더로 연동한 계정으로 "구글로 로그인"을 누르면 연동한 사용자로 로그인되고, 같은 구글 계정을 두 사용자가 연동할 수도 없다. 캘린더 연동은 일정을 읽는 권한일 뿐이므로, 로그인은 Better Auth에 맡기되 캘린더 연동은 우리 테이블에 따로 저장하는 자체 OAuth 흐름으로 구현한다. 동의, 콜백, 토큰 암호화 저장, 갱신, 철회를 모두 직접 처리한다.

## Consequences

- 캘린더 연동 계정으로는 로그인할 수 없고, 같은 구글 계정을 여러 사용자가 각자 연동할 수 있다.
- 로그인 계정과 같은 구글 계정을 연동해도 별도의 캘린더 연동으로 저장된다. 로그인 연결에 권한을 합치지 않는다.
- state 검증, PKCE, 토큰 갱신을 우리 코드가 책임진다. 테스트는 로그인과 같은 가짜 구글로 한다.
